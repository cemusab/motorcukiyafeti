# Askıya alınan kayıtlar

Üretici sitesi erişilemez olduğu için sitede kırık bağlantı/görsel bırakmamak adına geçici olarak yayından alınan kayıtlar. Geri koymak için JSON'daki `products`, `media`, `brand` kayıtlarını ilgili `src/data` dosyalarına ekle, `next.config.ts` içindeki ilgili yönlendirmeleri kaldır, `npm run qa` + `npm run links` + `npm run images`.
